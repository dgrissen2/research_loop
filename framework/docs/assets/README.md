# Plannotator guide — screenshots

The [USING_WITH_PLANNOTATOR.md](../USING_WITH_PLANNOTATOR.md) guide references screenshots that live here.
They are **captured by you** (Plannotator is a browser session), so v1 ships with this note instead of
binary images. Capture them against the worked example (`examples/cor1m-concentration-hedge/`).

Capture these, in order:

1. **The Plannotator interview step (UI).** Run `/plannotator-setup-goal` and screenshot the interview
   bundle in the browser UI → save as `plannotator-interview.png`.
2. **The facts review.** Screenshot the reviewed seed-hypotheses/facts step → `plannotator-facts-review.png`.
3. **Reading the hypothesis index + a linked hypothesis doc.** Open the index and a findings note it links
   to, showing how you navigate from the index to a hypothesis →
   `plannotator-index-and-finding.png` (or two shots: `plannotator-index.png` + `plannotator-finding.png`).
4. **Annotating a finding.** `/plannotator-annotate` on a findings note, showing inline feedback →
   `plannotator-annotate-finding.png`.

Drop the PNGs in this folder; the guide will render them. Suggested files: `plannotator-interview.png`,
`plannotator-facts-review.png`, `plannotator-index-and-finding.png`, `plannotator-annotate-finding.png`.
